# 活動內容
## 打人獲得糖果
- 從商店購買籃子（生涯只要購買一次）
- 持有籃子活動期間內只要打贏對手就有機率獲得 treats
  - 機率 = 籃子等級 + 籃子升級 + scary
  - 不分 leave / mug / hospital

## 世界boss
- 玩家可以消耗 9999 treats 召喚世界boss，參加打世界boss可以獲得大量treats，有看到必打
    - 每隻boss獎勵
      - 1個可以使用一整年的Relic
      - 100個大 Treats 箱子，打開可以獲得超大量 treats (200-300)
      - 999個小 Treats 箱子，打開可以獲得大量 treats (50-75)
    - 掉落方式與 NPC 相同，依照每個人在戰鬥中進行攻擊的次數提高抽獎比重，但是每個人只有一次獲得機會，建議只打一次就好
- 階段一: 在世界各地出現小王
  - 地區與Relic種類
    - Mexico: 可以重複閱讀以閱讀過的書本
    - Cayman: Passive 傷害+100%
    - Canada: Critical 機率+25%
    - Hawaii: 免去Drug的負面效果
    - United Kingdom: 可以不消耗地使用消耗品
- 階段二: 王在世界各地循環移動
  - Boss Relic: Energy, Nerve, Happy 恢復量變成兩倍
  - 王會依照小王被打死的順序移動
  - 出王的時候籃子升級會有額外三種武器可以買
    - 小刀: 可以穿透王的防禦
    - 防具：可以抵抗王的負面效果
    - 投擲：可以暫時性(15秒)讓所有人都穿透王的防禦，但是只能買一次=5個
    - 前期可以不用買，幾乎隨時都會有人丟穿透投擲道具讓大家一起爽

## 兌換糖果
- 依照建議的流程進行籃子升級
- 等到所有的升級都完成之後才開始兌換糖果(exchange treats)
  - 大約第三年開始可以獲利
  - 大家算出來的投資報酬率約為 2m-4m / 25e（不計算籃子滿之前的投資）

## 活動懶人包
- 有王先打王，盡量每隻小王都蹭一下
  - 摸到王的獲利期望值比打路人多太多了
  - 沒第一時間跟到的話大概就不用打Mexico
  - 距離越遠的會越晚死
- 盡量打一下就可以死掉的小菜雞，沒必要挑難打的對手
  - 可以用advanced search去找很弱的新人打
